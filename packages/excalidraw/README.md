# SynapDraw Core Canvas Component

SynapDraw çekirdek çizim tuvali React bileşen paketi.

## Kullanım

Uygulama içerisinde tam yüksekliğe sahip bir kapsayıcı (`100vh` veya `100%`) içinde render edilir.

```tsx
export default function CanvasView() {
  return (
    <div style={{ height: "100vh" }}>
      {/* SynapDraw Çizim Tuvali */}
    </div>
  );
}
```
