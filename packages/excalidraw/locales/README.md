## Dil Dosyaları (Locales)

SynapDraw çoklu dil desteğini bu dizindeki JSON dil paketleri üzerinden sağlar.

- `percentages.json`, her dil için çeviri tamamlanma oranlarını barındırır.
- Uygulama içi SDLC, Tasarım Tuvali ve AI Agent terimleri başta `tr-TR.json` ve `en.json` olmak üzere ilgili dil dosyalarında tanımlanır.
